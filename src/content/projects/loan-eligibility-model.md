This project examined loan-status prediction using approximately thirty input features. The workflow included data cleaning, preprocessing, exploratory visualization with Matplotlib and Seaborn, and advanced predictive modeling.

The reported evaluation reached 99% prediction accuracy. The project reinforced the importance of matching validation and data-splitting strategies to the structure of the dataset rather than relying blindly on a random split.
